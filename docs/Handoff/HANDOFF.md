# 날마다 조식 리뉴얼 — 구현 지시서 (B안 "아침 잡지")

## 0. 작업 원칙
- `design/` 폴더의 `.dc.html` 파일은 **시안(레퍼런스)** 이다. 그대로 복사하지 말고, 기존 사이트 코드베이스의 구조·빌드 방식에 맞춰 재구현한다.
  - `.dc.html`은 캔버스 에디터 전용 포맷이다(`<x-dc>`, `<sc-for>`, `{{hole}}`, `DCLogic`). 레이아웃·색·타이포·간격 값만 참고한다.
- 기존 기능(검색, 랜덤, 히트맵 데이터, 다국어 KO/EN, 투표)은 **동작을 유지**한 채 화면만 교체한다.
- 시안의 `[대괄호]` 값은 플레이스홀더다. 실제 데이터로 연결하고, 없으면 해당 요소를 숨긴다.
- 작업 전 코드베이스 구조를 파악해 **변경 계획을 먼저 보여주고 승인받은 뒤** 진행한다. 한 번에 한 페이지씩 진행한다.

## 2. 페이지별 요구사항
### 메인 (`B-Desktop`, `B-Mobile`)
- 제호 + 발행 정보: `Vol.` = 2020-07-13부터 오늘까지 일수(자동 계산), 누적 편수는 데이터에서 계산
- 검색바를 헤더 바로 아래에 배치
- 커버 스토리: 오늘 날짜의 과거 기록 중 1편 (선정 규칙은 설정값으로 분리)
- "해마다 오늘의 조식": 세로 목록, 사진 없는 항목은 썸네일 생략
- 소개글: 인용 1문장 노출 + "전문 읽기" 토글 (`<button aria-expanded>`)
- 히트맵: 데스크톱은 연도 탭 + 53주 그리드(월·요일 라벨, 범례, 오늘 테두리), 모바일은 **월별 달력**
- 출석률 = 기록한 날 ÷ 지나온 날

### 아카이브 (`Sub-Archive-*`)
- 필터: 날짜, 연도(체크박스+건수), 칼로리 범위, 재료 칩, "모두 지우기"
- 결과 수는 `aria-live="polite"`로 안내
- 필터 상태는 URL 쿼리로 유지 (공유·뒤로가기 대응)
- 모바일: 필터를 가로 칩 줄로, "필터" 버튼은 바텀시트

### 레시피 상세 (`Sub-Recipe-*`)
- kcal, 2인분 기준, 탄단지 비율 막대
- 재료 체크리스트 (체크 상태는 localStorage, try/catch 필수)
- 조리 단계 번호 목록, 다른 해 같은 날, 전날·다음날 이동, 인스타 원문 링크
- 모바일 하단 고정 바 (safe-area inset 반영)

### 명예의 전당 (`Sub-Hall-*`)
- 기간 탭(이번 달/올해/전체), 1–3위 대형, 4–10위 목록 + 투표 버튼(`aria-pressed`)

### 개인정보처리방침 (`Sub-Privacy-D`)
- 개인정보 보호법 제30조 필수 13개 항목 + "한눈에 보기" 요약 + 목차 앵커
- 실제 처리 항목은 **투표 기능 구현을 조사해서** 채우고, 확인되지 않은 값은 비워둔 채 보고한다

## 3. 보안 요구사항 (OWASP Top 10:2021 기준, 시큐어코딩 준수)
- **A03 인젝션/XSS:** 검색어·URL 쿼리·투표 응답 등 모든 외부 입력은 `textContent` 또는 템플릿 자동 이스케이프로 출력한다. 사용자 입력에 `innerHTML`, `eval`, 인라인 이벤트 핸들러를 쓰지 않는다. 서버 쿼리는 파라미터 바인딩만 사용한다.
- **A01 접근 통제 / A04 설계:** 투표는 서버에서 중복·빈도를 검증한다(클라이언트 검증만으로 신뢰하지 않음). 요청 빈도 제한을 적용하고, 상태 변경 요청은 POST로 받으며 CSRF 대책을 적용한다.
- **A05 보안 설정:** CSP(`script-src`는 자체 도메인 + 필요한 CDN만, `unsafe-inline` 지양), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `frame-ancestors 'none'`, HTTPS 강제(HSTS). 디렉터리 목록 노출과 상세 에러 노출을 금지한다.
- **A06 취약 구성요소:** 외부 라이브러리는 버전을 고정하고, CDN 스크립트에는 SRI(`integrity`)를 적용한다. `npm audit` 등으로 점검한다.
- **A02 암호화 실패:** API 키·토큰을 클라이언트 코드나 저장소에 두지 않는다(.env + .gitignore).
- **A09 로깅:** 투표 API의 이상 요청을 로깅하되, 로그에 개인정보는 최소화하고 보유 기간을 방침과 일치시킨다.
- **개인정보:** 수집 항목 최소화. IP 등을 저장한다면 해시·가명 처리와 보유 기간 후 자동 파기를 구현하고, 처리방침과 실제 동작을 일치시킨다.
